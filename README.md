# TP03 – Fire Monitoring Data Analysis Using Power BI

## Project Overview

This project presents an interactive Power BI dashboard for analyzing and visualizing synthetic fire-monitoring data.

The dashboard summarizes environmental measurements and alarm indicators, allowing users to compare different sensors and explore the dataset interactively.

## Objectives

- Import and inspect the monitoring dataset.
- Prepare data using Power Query.
- Create key performance indicators (KPIs).
- Visualize temperature and smoke levels by sensor.
- Analyze alarm counts.
- Use an interactive slicer to filter the dashboard by sensor.

## Dataset

The synthetic dataset contains 10,000 records and seven columns:

- `timestamp`
- `sensor_id`
- `temperature`
- `humidity`
- `smoke_level`
- `fire_alarm`
- `sensor_status`

The alarm indicator was generated using predefined temperature and smoke-level thresholds.

## Tools and Technologies

- Microsoft Power BI Desktop
- Power Query
- CSV

## Main Results

- Total records: 10,000
- Alarm-labelled records: 750
- Alarm-labelled record percentage: 7.5%
- Average temperature: 29.93
- Average humidity: 52.69

These results describe the synthetic dataset and should not be interpreted as real-world fire statistics.

## Dashboard Features

- KPI cards
- Average temperature by sensor
- Average smoke level by sensor
- Alarm count by sensor
- Clustered column chart
- Interactive sensor slicer
